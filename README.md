# Gurises

App web (PWA) gratuita y de código abierto para organizar el cuidado de los chicos: calendario, bloques de cuidado, pendientes y enlaces a documentación. Pensada para el celular.

**Tus datos quedan solo en tu dispositivo.** No hay cuentas, ni servidor, ni nube.

## Uso

- https://abelg88.github.io/gurises/
- Instalala desde el navegador ("Agregar a la pantalla de inicio").
- La primera vez te pide el nombre del hijo/a. Podés agregar más desde el selector.

## Respaldos (importante)

Como los datos viven en el navegador, borrar los datos del sitio o cambiar de celular los pierde.
- **Más → Respaldo de todos**: descarga un `.json` con todos los chicos.
- **Restaurar respaldo** (pantalla inicial / selector): vuelve a cargarlo, también en otro celular.
- La app avisa cada 14 días si hace falta respaldar.

## Qué incluye

Calendario y bloques de cuidado (con horas por cuidador), plantillas, exportar PDF/.ics, pendientes y documentos.
